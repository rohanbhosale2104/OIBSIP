# Unemployment Analysis with Python

## Project Overview
This project explores unemployment trends in India using Python and data analysis techniques, with particular attention to regional differences and the impact of COVID-19.

## Objectives
- Analyse unemployment data across Indian states or regions.
- Examine monthly and regional unemployment trends.
- Visualise patterns using charts and graphs.
- Compare unemployment rates before and after COVID-19.

## Technologies Used
- Python
- Google Colab / Jupyter Notebook
- Pandas
- Matplotlib
- Seaborn

## Project Files
- `Unemployment_Analysis.ipynb` — notebook containing the analysis and visualisations.
- `screenshots/` — selected output charts and results.
