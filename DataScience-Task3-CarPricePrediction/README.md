# Car Price Prediction Using Machine Learning 🚗

## 📌 Project Overview
This project aims to predict the selling price of a used car using machine learning regression techniques. It analyses vehicle features such as brand, age, mileage, fuel type, and transmission to estimate the car's selling price.

The project is implemented in Python using Google Colab in Jupyter Notebook (`.ipynb`) format.

## 🎯 Objectives
- Analyse used-car data to understand pricing patterns.
- Clean and preprocess the dataset.
- Explore relationships between car features and selling prices.
- Build a regression model to predict used-car prices.
- Evaluate model performance using appropriate regression metrics.
- Visualise the data and prediction results.
